Slack integration

✓ Webhook configured ✓ Real @-mentions enabled @-mentions: plain text only Last digest posted: — (next reminder ~24h after that). No digest posted yet.
Not configured. Set the SLACK_WEBHOOK_URL environment variable to an incoming-webhook URL for the channel that should receive review reminders, then restart the app. Once configured, a scheduled job posts a digest of pending questions once every 24 hours until the queue is cleared.
Optional — turn @-mentions into real Slack pings: The digest currently lists domain admins as plain text (no notification). To upgrade to real @Amit Revankar-style pings that ring the recipient's Slack:
  1. In your Slack app → OAuth & Permissions, add the bot-token scope users:read.email (and users:read if missing), then reinstall the app.
  2. Copy the Bot User OAuth Token (starts with xoxb-).
  3. Set SLACK_BOT_TOKEN on the platform and redeploy.
Without the token, names still appear in the digest — they just don't trigger a notification. The recipient's Slack account email must match their app account email for the lookup to succeed.
